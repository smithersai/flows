# 23.5 — `/reset` neither resets nor says it cannot

**Lane** honesty (§23) · **Origin** https://canary.smithers.sh ·
**Bundle** `assets/index-BHHXuMoZ.js` · **Observed** 2026-08-19, account
`codeplanesmithers` (`{"login":"codeplanesmithers","allowlisted":true,"admin":false,"scopes":["read:user"]}`).

**Row** 23.5 — "`/reset` starts a fresh conversation and states that nothing is
kept."

## Steps

1. Sign in on https://canary.smithers.sh.
2. Seed a marker: `Say exactly: <MARKER> and nothing else.` Confirm it is in the
   transcript.
3. Type `/reset` and submit.
4. Read the transcript.

## Expected

A fresh conversation, and a line saying nothing was kept.

## Actual

Nothing is reset. The marker is still there. No line explains anything. The
model answers with the literal text `/retry` — on an earlier run it ran the
`retry` flow and answered "What would you like to do next?".

```
/reset
02:14 AM
Reasoning complete
› Reasoning
/retry
02:15 AM
```

## Cause

`reset` is declared inside `adminFlows` (`apps/ui/src/mainview/flows/Flows.ts`,
"The bare reset is admin-only dev tooling (§2): no sweep, nothing kept"), and
`adminFlows` registers only when the validated session carries `admin:true`.
For every other session `parseSubmit`
(`apps/ui/src/mainview/flows/registry.ts`) finds no command named `reset`,
returns `{ kind: "prompt" }`, and the literal string `/reset` is handed to the
model as chat text. The model then reaches for whatever it can see.

So the row as written is only reachable by an admin. But the *observed*
behaviour for everyone else is the honesty problem: an unrecognised slash
command is silently routed to the agent, which may invoke an unrelated flow.
`/issues.list` proves the honest shape exists — it answers
"`/issues.list` didn't run — Several repositories are watched … name one as
owner/repo". `/reset` gets no such line.

`ADMIN_LOGINS` on the canary identity worker is `roninjin10`; the only test
login available to this lane is `codeplanesmithers`, so the admin path was not
exercised (see row 24.7).

## Route / selector

- composer `textarea.sui-chat-composer-input`
- `apps/ui/src/mainview/flows/Flows.ts` `adminFlows` → `name: "reset"`
- `apps/ui/src/mainview/flows/registry.ts` `parseSubmit`
