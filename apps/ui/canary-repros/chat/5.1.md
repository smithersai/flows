# 5.1 — bare `/` leads with a recommendation that is drawn off-screen, and Enter runs the wrong flow

- **Origin:** https://canary.smithers.sh
- **Tested:** 2026-08-18, signed in as `codeplanesmithers` (a recommendation is waiting, so `reco.accept` is the gold lead)
- **Selectors:** `.slash-menu`, `.slash-menu [role=option]`, `.slash-menu-name`, `[data-gold]`, `[aria-selected]`
- **Screenshot:** `/tmp/canary-chat-5.1.png`
- **Same root cause as:** [5.6](./5.6.md) — the 8-item cap is not applied to a bare `/`

## Steps

1. Sign in at https://canary.smithers.sh at a 1400×1000 viewport.
2. Click into the composer with the mouse and leave the pointer where it landed
   (this is how a mouse user focuses it).
3. Clear the draft, then type a single `/`.
4. Read `.slash-menu`'s box and which `[role=option]` carries `aria-selected="true"`.

## Expected

Row 5.1: "`/` opens the menu with the recommended flow first, and bare `/` +
Enter runs it." The leading item is `/reco.accept`, it is visible, and it is the
one Enter runs.

## Actual

`/reco.accept` **is** ordered first and carries `data-gold="true"`, but it is
never shown and never run:

```
total options ............ 65
menu height .............. 2073px   in a 1000px viewport
menu top ................. -1114px  (35 of 65 rows above the window)
menu bottom .............. 959px    (the composer starts at 980px)
overflow-y / max-height .. visible / none   -> the off-screen rows cannot be scrolled to
first option ............. /reco.accept at top -1109px
aria-selected ............ index 63, /admin.feedback
```

Two consequences:

- **A.** The listing is taller than the window and `.slash-menu` sets no
  `max-height` and no scrolling, so the top 1114px — including the leading
  recommendation — is unreachable.
- **B.** The menu's bottom edge overlaps the composer, so the pointer that
  focused the composer sits on option 63 and fires `onMouseEnter`, which sets
  the highlight (`App.tsx` `onMouseEnter={() => setSlashMenu({ …, index })}`).
  Pressing Enter runs `/admin.feedback`, an admin debug read, not the
  recommendation. Reproduced 3/3 on reloads.

Keyboard-only the row passes: park the pointer away from the menu
(`page.mouse.move(1350, 20)`) before typing `/` and `aria-selected` is index 0,
`/reco.accept`, and Enter runs it. The failure needs a mouse, which is the
ordinary way to focus a composer.
