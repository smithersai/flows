# 28.10 — the app has no favicon

Origin: <https://canary.smithers.sh> (bundle `assets/index-BHHXuMoZ.js`)
Tested: 2026-08-19, admin lane round 1

## Checklist row

> **28.10** The browser tab title and favicon are right.

## Steps

1. Load <https://canary.smithers.sh>.
2. Read `document.title` and `document.querySelectorAll("link[rel*='icon']")`.
3. `GET /favicon.ico`.

## Expected

Title "Smithers" and a Smithers favicon in the tab.

## Actual

```
document.title      : "Smithers"
link[rel*=icon]     : []
GET /favicon.ico    : {"status":404,"bytes":0}
```

The title is right. There is no favicon anywhere: the served `<head>` is

```html
<meta charset="UTF-8" />
<meta name="viewport" content="width=device-width, initial-scale=1.0" />
<title>Smithers</title>
<script type="module" crossorigin src="/assets/index-BHHXuMoZ.js"></script>
<link rel="stylesheet" crossorigin href="/assets/index-DKyCZKgi.css">
```

so every tab, bookmark, and history entry shows the browser's default blank
icon. `apps/ui/public/` ships no icon for vite to copy.

## Route / selector

`GET /` (`<head>`), `GET /favicon.ico` on `smithers-mvp-web`.

