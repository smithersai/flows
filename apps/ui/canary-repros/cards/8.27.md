# 8.27 — the file card shows binary as base64 and swallows a missing file

- **Origin:** https://canary.smithers.sh (bundle `/assets/index-BHHXuMoZ.js`)
- **Account:** `codeplanesmithers`
- **Repro:** `bun apps/ui/canary-repros/cards/8.27.ts`
- **Screenshot:** `/tmp/canary-cards-8.27-file.png`, `/tmp/cardslane/binary-card.png`
- **Route:** `GET /api/repos/{owner}/{repo}/contents/{path}`

## Fixtures used

Created by this lane on `codeplanesmithers/canary-sandbox` (GitHub web upload as
`codeplanesmithers`) and imported into Smithers Cloud with
`/repos.import codeplanesmithers/canary-sandbox`:

- `big.txt` — 1200 lines, 162 KB
- `blob.bin` — 4 KB of random bytes

## Steps

Run each of the four sub-cases the row names:

1. `/files.read README.md codeplanesmithers/canary-sandbox` — text
2. `/files.read big.txt codeplanesmithers/canary-sandbox` — large
3. `/files.read blob.bin codeplanesmithers/canary-sandbox` — binary
4. `/files.read does-not-exist.txt codeplanesmithers/canary-sandbox` — missing

## Expected

1. renders the file, 2. renders bounded and says it is truncated, 3. says the
file is binary and offers a download rather than printing bytes, 4. says the
file is not there.

## Actual

1 and 2 pass. `README.md` renders. `big.txt` renders and is cut at 122 lines
with "Truncated — the full file stays in the repository."

**3 fails.** `blob.bin` is rendered as raw base64 text, as if it were source: one
line laid out **42626px** wide inside a **686px** box (see 7.8 for the overflow
that causes). Nothing on the card says the file is binary and there is no
download.

**4 fails.** The missing file produces no card and no transcript line at all —
the contents route answers 404 and the app swallows it. This is the same silent
path as row 7.7.

## Repro output

```

big.txt: card present: true, truncation notice: true
blob.bin: card present: true, names it binary: false, pre 42626px inside 686px
missing file: card present: false, transcript said ""
FAIL 8.27: binary file rendered as raw base64 text with no binary notice; missing file produced no card and no message
```

Exit code 1.
