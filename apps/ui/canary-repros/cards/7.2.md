# 7.2 — a maximized card hangs off the right edge of the viewport

- **Origin:** https://canary.smithers.sh (bundle `/assets/index-BHHXuMoZ.js`)
- **Account:** `codeplanesmithers` (allowlisted, admin)
- **Repro:** `bun apps/ui/canary-repros/cards/7.2.ts`
- **Screenshot:** `/tmp/canary-cards-7.2-maximized.png`
- **Selector:** `[data-kind="balance"] [data-flow="card.maximize"]` /
  `[data-flow="card.minimize"]`

## Steps

1. Sign in on https://canary.smithers.sh with the persistent Playwright profile.
2. Run `/billing.balance` to put one card in the transcript.
3. Click the card's `[data-flow="card.maximize"]` button in a 1280x900 viewport.
4. Measure the card's bounding box against `document.documentElement.clientWidth`.

## Expected

The maximized card fits inside the viewport, so every control it owns — its own
minimize button and any right-aligned action buttons in its body — is fully
visible and clickable.

## Actual

The maximized card is laid out **1280px wide starting at x=24** in a **1280px**
viewport, so it overhangs the right edge by 24px. `document.documentElement`
does not scroll horizontally (`scrollWidth === clientWidth === 1280`), so the
overhanging strip is unreachable. The card's own minimize button sits at
x=1259..1291 and is clipped; on a maximized `workflow-list` card every `Run`
button (x=1251..1291) is clipped the same way.

The three behaviours the row names do work and are asserted by the repro so a
fix cannot regress them: `data-maximized` flips to `true`, Escape returns it to
`false`, and focus moves to `card.minimize` while maximized and back to
`card.maximize` after Escape.

## Repro output

```
data-maximized: true
card box: {"left":24,"right":1304,"width":1280}
viewport: {"clientWidth":1280,"scrollWidth":1280}
minimize button box: {"x":1259,"y":35,"width":32,"height":32}
focus after maximize: card.minimize; after Escape: card.maximize; data-maximized: false
FAIL 7.2: the maximized card is 1280px wide at x=24 in a 1280px viewport — it hangs 24px off the right edge, clipping its own minimize button, and the document cannot scroll horizontally to reach it.
```

Exit code 1.
