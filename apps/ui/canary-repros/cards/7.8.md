# 7.8 — long card content overflows the card instead of scrolling inside it

- **Origin:** https://canary.smithers.sh (bundle `/assets/index-BHHXuMoZ.js`)
- **Account:** `codeplanesmithers`
- **Repro:** `bun apps/ui/canary-repros/cards/7.8.ts`
- **Screenshot:** `/tmp/canary-cards-7.8-overflow.png`
- **Selector:** `[data-kind="file"] .smithers-card-body`, `[data-kind="file"] pre`

## Fixtures used

Created by this lane on `codeplanesmithers/canary-sandbox` (GitHub web upload as
`codeplanesmithers`) and then imported into Smithers Cloud with
`/repos.import codeplanesmithers/canary-sandbox`:

- `big.txt` — 1200 lines, 162 KB
- `blob.bin` — 4 KB of random bytes, served back as one base64 line

## Steps

1. Open https://canary.smithers.sh signed in, viewport 1280x900.
2. Run `/files.read big.txt codeplanesmithers/canary-sandbox`.
3. Run `/files.read blob.bin codeplanesmithers/canary-sandbox`.
4. Measure each card's body and its `<pre>`.

## Expected

Long content scrolls **inside** the card: the body is bounded and scrolls, and
long unbroken lines get a horizontal scroller within the card's own border.

## Actual

The card body carries `overflow-y: visible; max-height: none` and the `<pre>`
carries `overflow: visible`, so nothing is bounded and nothing scrolls.

- `big.txt` grows the card to **2438px tall**, and its lines lay out **1045px**
  wide inside a **686px** box — 346px of every line paints past the card's own
  right border (card right edge x=996) across the page background.
- `blob.bin` lays out one base64 line **42626px** wide inside the same 686px
  box: ~41900px of content past the card's right border.

The document itself does not scroll horizontally
(`scrollWidth === clientWidth === 1280`), so the overflowing text is clipped at
the viewport edge and is unreachable — the second half of the row's assertion
holds only because the overflow is silently thrown away.

The `file` card does truncate very long files at 122 lines with "Truncated — the
full file stays in the repository", so the height problem is bounded in
practice; the horizontal overflow is not bounded at all.
