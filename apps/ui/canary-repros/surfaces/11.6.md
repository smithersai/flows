# 11.6 — Zero connectors renders an empty state that names the next step

- **Origin:** https://canary.smithers.sh (Worker `smithers-mvp-web`, deployment `4cd23e9a-14a0-4947-8d45-2bc7c59e0db0`)
- **Account:** `codeplanesmithers` (no repositories connected)
- **Verdict:** FAIL — the empty state states the condition and names no next step.

## Steps

1. Sign in on https://canary.smithers.sh with an account that has no connected
   repositories.
2. Run `/connect` to open the Connectors pane.
3. Read the "Connected repositories" section.

## Expected

An empty state that names what to do next — the same grammar the World pane
uses ("No World notes yet" / "Smithers will keep what it learns here." /
**Create a note**).

## Actual

One line, no description, no affordance:

```
empty-state text: "No repositories connected"
actionable elements inside the empty state: 0
```

## Root cause

`apps/ui/src/mainview/ConnectorsSurface.tsx` renders the zero case as

```tsx
<div className="connector-empty">
  <FolderGit2 size={20} />
  <div><strong>No repositories connected</strong></div>
</div>
```

with no description and no action, while the same file's sibling surfaces use
`EmptyState` with a title, a description and an action. The gap matters more
here than elsewhere: on the web origin the only listed way to add one is
**Import** (`repos.import`) further up the pane, and `connector.add` answers
"Local repositories can only be connected from the Smithers native app", so a
reader who is not told where to go has nowhere obvious to look.

## Selectors / routes

- Pane: `section.connectors-surface`
- Empty state: `.connected-repositories .connector-empty`
- The affordance it should point at: `[data-flow="repos.import"]`
